This is an example blog post. To add a new post, copy this file into
`src/content/blog/` with a new filename (e.g. `my-second-post.md`), and
change the `title`, `description`, and `pubDate` in the frontmatter.

It will automatically appear on the [blog index](/blog/), newest first,
and get its own page at `/blog/<filename>/`.
